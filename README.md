# Prottoy — Product Designer

Portfolio website of **MD Rakkibul Islam Prottoy**, a product designer working on UI/UX, brand and technology.

**Live site:** https://mdrakkibul38-png.github.io/portfolio/

## What's inside

- An interactive 3D hero with physics and a fluid cursor effect
- A Featured Work section where every project opens as a case study:
  brief, problem, process, design system and the final screens, each told with interactive pieces
- Smooth scrolling and reversible scroll animations

## Built with

HTML, CSS and JavaScript, using [Three.js](https://threejs.org/), [GSAP](https://gsap.com/), [Lenis](https://lenis.darkroom.engineering/) and Rapier physics.
No build step: open `index.html` through any static server.
